# Naoke ComfyUI AI Random Prompt · Full-Dimension Character Prompt Generator

> 一个面向主流AI绘画模型的全维度人物提示词随机生成器（ComfyUI / SD1.5 / SDXL / Flux / NAI / Z-Image / Qwen-Image 等）。
> A full-dimension character random prompt generator for mainstream AI art models (ComfyUI / SD1.5 / SDXL / Flux / NAI / Z-Image / Qwen-Image, etc.).

## 功能特性 / Features
- 一键随机生成完整**英文 + 中文 + 负面提示词** / One-click random generation of complete **English + Chinese + negative prompts**
- 覆盖身份 / 头部 / 身材 / 场景 / 着装 / COS角色 / 镜头 全维度 / Covers identity / head / body / scene / clothing / COS character / camera full dimensions
- 内置家族加权随机、姿势×镜头智能联动 / Built-in family weighted randomness, pose × camera smart linkage
- 防走光安全词、收藏与预设系统、局部重绘指令库 / Anti-exposure safety words, favorites & presets, local inpaint instruction library
- 主流分辨率推荐、历史记录、搜索与拼音搜索 / Mainstream resolution recommendations, history, search & pinyin search
- 本地绿色运行，无需联网 / Runs locally, no network required

## 使用方法 / Usage
下载安装包 → 安装 → 打开程序 → 点击「全部随机」→ 一键复制提示词到 ComfyUI / SD 使用。
Download the installer → Install → Open the app → Click "Random All" → Copy prompts to ComfyUI / SD.
